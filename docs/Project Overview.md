Project Overview
Name: Enterprise IT Portfolio & Access Management SystemVersion: 1.0.0Executive SummaryThis system is an enterprise-grade platform designed to act as a centralized registry for IT Assets (Applications), Organizational Units (Departments), External Partners (Vendors), and Personnel (Users).Its core capability is a robust, historically-tracked Matrix Assignment system that governs and audits which users have access to which applications, including their specific roles on those applications.Primary GoalsAsset Visibility: Maintain a categorized, searchable inventory of all IT applications, their environments, and operational statuses.Access Governance: Track granular application assignments. Ensure an audit trail of who assigned the role, when it began, and when it ended.Vendor Tracking: Seamlessly manage external vendors and map external contractors to their respective companies.Scalability & Security: Utilize a stateless API architecture (Laravel 12 + Sanctum) and a highly responsive, type-safe SPA (React 19 + TypeScript).

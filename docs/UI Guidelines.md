UI & UX Guidelines
1. The Hybrid UI ApproachWe merge two powerful systems to get the best results:TailAdmin: Used for the macro-layout. This provides a battle-tested, responsive Sidebar, Header, and main content area container.shadcn/ui: Used for all micro-components inside the content area. We generate DataTables, Dialogs, Selects, Comboboxes, and Forms using shadcn.
2. Styling RulesCSS Variables: The tailwind.config.ts must be carefully merged so shadcn's --primary variable aligns with TailAdmin's brand colors.Icons: Use lucide-react (standard with shadcn).
3. User Experience (UX) MandatesNotifications: Use Sonner for non-intrusive toast alerts on CRUD success/failure.Loading States: Avoid full-page spinners. Use shadcn Skeleton components matching the layout of the loading data (e.g., Table row skeletons).Empty States: When a table has 0 records, display a visual empty state with a "Create New" Call-To-Action.Error Boundaries: Isolate React feature pages with Error Boundaries so a crash in one widget does not white-screen the whole app.

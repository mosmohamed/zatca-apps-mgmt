Testing & QA Guide
1. Backend Testing (Pest or PHPUnit)Feature Tests: Every API endpoint must have a corresponding Feature test verifying:Validation rules (expect 422).Authorization (expect 403 for unauthorized roles).Successful CRUD operations (expect 200/201) mapping to database assertions.Service Tests: Unit test complex business logic inside Services. Specifically, test that adding a new ApplicationAssignment properly updates the ended_at timestamp for previous assignments.
2. N+1 Query PreventionEnsuring Model::preventLazyLoading(!app()->isProduction()); in AppServiceProvider guarantees that if any Feature Test triggers lazy loading, an Exception is thrown, intentionally failing the test.
3. Frontend QAZod Schemas: Verify that Zod schemas perfectly mirror Laravel Form Requests rules.RTL Testing: Switch to Arabic language and verify TailAdmin sidebar alignment and shadcn dropdown alignments.State Management: Ensure TanStack Query cache invalidations trigger correctly so data tables update immediately after a Create/Update/Delete mutation without a manual browser refresh.
